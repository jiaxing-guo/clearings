# Context-selection review regressions

This supplement was authored after the candidate during PR review. It does not replace the pre-authoring `context-selection-v1` packet or extend the scope of its saved results.

Ten cases check evidence membership after operation group six, after the first distinct ID within operation and state evidence lists, and exclusion when the owning operation is unselected. Expected outputs are explicit, independent of the program and host adapter. Tests require these cases to detect implementations that scan only six groups or the first item of each evidence list.

The manifest freezes these regression bytes separately. Current selection checks and evaluation run both packets and report their scopes separately. This is regression evidence, not an independent agent trial or universal correctness proof.
