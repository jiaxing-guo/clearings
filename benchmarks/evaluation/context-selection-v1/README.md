# Frozen context-selection evaluation

This packet defines a bounded evaluation of state and declared-source selection. It was committed before the selection program was authored. The evaluator uses relational membership, separate from the production adapter and candidate implementation. This is continuing-session development with separately defined expectations; it is not an independent coding-agent trial.

`contract.json` freezes the entry signature, return type, logical limits, domain counts, and obligations. `cases.mjs` enumerates 4,632 cases: 4,096 state-incidence combinations, 512 evidence-incidence combinations, six explicit boundary cases, and 18 larger sparse/dense/complete-frame cases and permutations. `oracle.mjs` supplies membership expectations and explicit failure/unknown classification. `controls.mjs` defines 15 faults. The manifest binds the packet bytes; change the evaluation version rather than silently updating this packet for a candidate.

The two-operation/two-state domain exhausts selected sets, complete-frame assignments, and all read/write relations. The one-operation/one-state/one-source domain exhausts presence at all six operation evidence positions and the state evidence position, with operation and state membership. These are separate factorized domains, not the Cartesian product of arbitrary metadata on arbitrary graphs. The larger cases use 16, 64, and 128 records. General scalability and universal correctness remain unestablished.

The generic typed projection accepts duplicate metadata rows and unknown identifiers: matching rows contribute by existential membership and absent catalog IDs cannot be returned. Production specification validation continues to reject invalid specifications before adaptation. Syntax/type/portability failures are argument-admission errors; no application-failure code is declared by this algorithm. Successful results must be unique and sorted by UTF-16 code units. The adapter's six schema positions and exclusion of literal keys are checked directly against explicit original-record expectations, independently of this normalized-domain oracle.

Run `npm run test:selection:contract` from the repository root. The tests check packet hashes, independent bit-equation and table expectations, all fault controls, unavailable execution, and adapter ownership. The existing context-assembly contract supplies the outer `return-states` and `return-evidence` obligations. This packet narrows their algorithm boundary and does not claim source authentication or claim support.
