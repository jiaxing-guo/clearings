Clearings represents repository structure and proposed behavior, assembles bounded agent context, and checks supplied observations against typed contracts.

## Learn Clearings

[Your first operation contract](/docs/technical/learn/first-contract) follows one Hono behavior question through abstract values, a guard, a postcondition, and three check results. It introduces the distinctions needed to interpret a verdict.

Then [compare the observations](/docs/technical/semantics/operations) in the operation explorer. Inspect the exact contract alongside the observation and its individual rule checks.

## Complete a task

- [Check a Hono case](/docs/technical/guides/check-a-case): prerequisites, CLI commands, expected results, and troubleshooting.
- [Author and review a specification](/docs/technical/guides/author-and-review): define accepted and rejected writes, constrain state and effects, and check adjacent observations.
- [Run the documentation locally](/docs/technical/development/documentation#run-the-documentation-locally): install dependencies and start a browser preview with automatic Markdown regeneration.
