Use Node.js 24, npm 11, and Git 2.51 or later. Linux and macOS are the supported environments; verification currently runs on Linux. Windows support is pending because Git isolation uses `/dev/null`.

The package is not published to npm. Build from a repository checkout and run all commands from its root. For the compiler and interpreter workflow, start with [Run and inspect a program](/docs/technical/guides/run-programs). This page covers the historical source-inspection example.

## Install and build

```bash
npm ci --ignore-scripts
npm run build
```

## Find a behavior

```bash
node dist/cli/main.js inspect benchmarks/results/hono-contracts/semantic.json
node dist/cli/main.js inspect benchmarks/results/hono-contracts/semantic.json --behavior response-selection
```

The first command lists canonical IDs and aliases. The second returns a selected record and its direct links. Find `outcomes`: each entry pairs a condition with assertion IDs. Those assertions contain the explanation and its evidence IDs.

This example distinguishes a direct nullish result from a falsy Promise result. Only the Promise fallback consults `finalized` before choosing stored response state. The [engineer guide](/docs/demos) explains the branches in reading order.

## Export context

```bash
node dist/cli/main.js context benchmarks/results/hono-contracts/semantic.json --behavior response-selection --max-bytes 131072 --no-neighbors
```

The result is compact JSON. `budget.used_bytes` counts its exact UTF-8 bytes, including the final newline. The pack retains required rules and critical unknowns. It includes source references; exact source text remains available through evidence lookup.

To save with `--out`, also supply `--repository`. That path protects the target from output writes. Add `--scan` as well if you need source revalidation.

## Reproduce the three demos

```bash
npm run benchmark:fetch
node scripts/replay-contracts.mjs benchmark-checkouts/hono.git benchmarks/results/local/my-contracts
node scripts/build-shared-demo.mjs benchmark-checkouts/hono.git benchmarks/results/local/my-contracts benchmarks/results/local/my-demo
```

Use new output directories. The first command fetches the pinned bare Hono repository; skip it if that checkout already exists. Replay reads immutable Git objects, checks the recorded proposal, and writes a fresh scan and model. The final command produces four HTML reports, four Markdown reports, and the internal walkthrough.

Open `benchmarks/results/local/my-demo/index.html` locally. The reports contain their own styles and scripts. No target dependencies are installed and no target code runs.

The recorded comprehension answers are copied into the review bundle. Rebuilding the bundle does not run an agent again.
