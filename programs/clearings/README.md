# Clearings algorithms in Program IR

[Required dependency closure](required-dependency-closure.json) is an authored executable implementation of Clearings' ordered graph-closure kernel. Its [semantic contract](../../docs/02-semantics/06-required-dependency-closure.md) defines argument types, ordering, duplicate handling, failures, and its relation to context assembly.

The interpreter consumes the committed JSON program. The adjacent [authoring module](required-dependency-closure.mjs) makes its typed syntax easier to review and reproduce; it does not compute a closure from invocation data. The [example arguments](required-dependency-closure.arguments.json) produce `["root", "a", "z", "y", "b"]` under the reference interpreter.

From the repository root:

```bash
npm run build
node scripts/build-required-closure-program.mjs
npm run test:program
```

Generation seals and validates the program, then writes its canonical content identity and formatted JSON. The tests compare regenerated bytes with the committed artifact, execute it against 1,536 exhaustive three-node graph cases and targeted expectations, and preserve the production context-assembly boundary. The semantic reference includes a runnable library example. Program CLI commands remain the next integration step.
